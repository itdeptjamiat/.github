# Assalamualaikum

**Islami Jamiat-e-Talaba (IJT)** is the **oldest and largest student organization in Pakistan** founded in **December 1947**.

* We help students with admissions, guidance, books, and hostel support.
* We organize educational activities like study circles and lectures.
* We protect student rights such as fair fees and better campus facilities.
* We build character through discipline, leadership, and Islamic values.
* We run welfare work like blood camps, scholarships, and relief efforts.
* We take part in campus elections and represents students.
